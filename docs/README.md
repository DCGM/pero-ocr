# pero-ocr docs

General rules for working on the parts of pero-ocr: what must hold, why, and how to check it. `AGENTS.md` at the top
is the short version that must not be broken; the documents here explain each part in full.

| document | for whom |
|---|---|
| [`benchmark.md`](benchmark.md) | whoever works with the benchmark (`benchmark/`) or changes anything in pero-ocr that can influence it |

How the tests are organised is in `test/README.md`, how the benchmark is run in `benchmark/README.md`.
