# LMX delinearizer

Conversion of LMX (Linearized MusicXML) to MusicXML, copied unchanged from
https://github.com/Fufec/olimpic-icdar24 (commit e9c0a4b), a fork of
https://github.com/ufal/olimpic-icdar24 that adds the staccatissimo articulation.

Only `linearization/Delinearizer.py` and the files it imports are included.
